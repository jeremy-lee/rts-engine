# ADR-0001：许可证选择

- 状态：**待用户确认**
- 日期：M0
- 决策者：项目所有者

## 背景

开源 2D RTS 引擎需要确定许可证。候选：
- **Apache-2.0**：商业友好、专利授权明确、与 MIT 一样宽松但多了专利条款
- **MIT**：最宽松、最短、社区接受度最高
- **GPL-3.0**：强制衍生作品开源（若希望引擎保持开源生态可考虑）

## 决策

**建议 Apache-2.0**，理由：
1. 明确专利授权（游戏引擎涉及大量算法，专利风险需覆盖）
2. 商业友好（便于未来接商业 Mod / 商业使用）
3. 与 OpenRA 的 GPL 不同——我们不复制其代码，只借鉴架构，不受 GPL 传染
4. 对 Mod 社区友好（数据驱动设计配合宽松许可证）

若用户希望「任何修改都必须开源」，则改用 GPL-3.0。

## 影响

- 一旦发布，许可证不可撤销（已发布版本）
- 所有第三方依赖必须兼容（当前零依赖，M3 引入渲染库时需复核）
- 文件头部版权声明需统一
