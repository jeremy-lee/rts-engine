# 像素军武风格资产生成配方

这套参数是经过多轮对比 RA 原版 sprite **量化验证**出来的，不要再凭感觉调。
改动任何一项之前，先跑一遍下面的"验收指标"。

## 一、整条链路

```
程序化 / CC0 3D 模型
   ↓ Blender 渲染（固定正交尺度，128px）
   ↓ lowres_sprite.py：每帧独立裁剪，【不缩放】
   ↓ 排除阵营色 → 预加噪点 → Bayer 抖动 → 量化
   ↓ 纯黑描边
24~30px 的 RA 风格 sprite
```

## 二、参数（已验证）

```bash
blender --background --python tools/blender_vehicles.py -- \
    artifacts/veh --facings 32 --size 128 --variants 1 --only ww2_medium

python tools/lowres_sprite.py artifacts/veh ww2_medium \
    assets_raw/ra/temperat.pal artifacts/final \
    --facings 32 --max 24x32 --dither 0.5 --grain 0.35 \
    --colours 12 --outline black --contrast 1.0
```

## 三、验收指标（和 RA 原版对比）

拿 `2tnk-0000.png` 当基准，逐项量：

| 指标 | RA 原版 | 合格区间 |
|---|---|---|
| 颜色数 | 13 | 11-15 |
| 亮度最小值 | 0（有纯黑） | **必须 = 0** |
| 相邻像素变化率 | 65% | 62-75% |
| 每帧尺寸 | 13×17 → 24×18 | **各帧不同**，不要统一 |

测量脚本见 `tools/lowres_sprite.py` 旁的对比命令，或直接用 numpy 数。

## 四、四个必须记住的坑

### 1. sRGB / 线性空间（**影响最大**）

Blender 的 `Base Color` 接受**线性值**，而调色板颜色都是 **sRGB**。

```python
# 错：直接填 sRGB，渲染出来蓝通道翻倍 → 奶油白
mat("body", (0.97, 0.84, 0.47))

# 对：先转线性
def s2l(c):
    return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4
mat("body", (s2l(0.97), s2l(0.84), s2l(0.47)))
```

实测：想得到 sRGB (247,215,121)，直接填会渲染成 (250,237,183)。
转换后渲染出 (235,203,117)。

**这一项错了，后面所有颜色调整都是白费。**

### 2. 每帧独立取景，不要并集缩放

RA 的 8 个朝向 bbox 各不相同（13×17、17×18、21×18、24×18…），
因为**每帧单独取景**。用所有帧的并集 bbox 统一缩放会把 sprite 压到画布 1/3，
而且失去尺寸变化。

### 3. 排除调色板索引 0-15

`temperat.pal` 前 16 项是**饱和阵营色**（洋红/青/绿/黄/红/蓝），
OpenRA 用来做玩家配色重映射。抗锯齿边缘像素会误落进去，产生彩色杂点。

### 4. 抖动之前必须先加噪点

Blender 的面是**纯平填充**，有序抖动无处可抖。
先加 `--grain 0.35` 的高斯噪声，量化后才有颗粒。
实测：不加噪点相邻变化率 50%，加了之后 70%（RA 是 65%）。

## 五、试过但**无效**的

| 尝试 | 结果 |
|---|---|
| 对比度拉伸 1.6 / 2.2 | ❌ 糊成粉白（按通道百分位拉伸破坏色彩关系） |
| 直接渲 48px / 96px 再缩放 | ❌ 比渲 512 更平（低分辨率下模型没细节可采样） |
| 高模（找来的军事模型） | ❌ 降到 24px 细节全丢，且授权难搞 |
| 并集 bbox 统一缩放 | ❌ sprite 只占画布 1/3，且各朝向尺寸一致（RA 是变化的） |

## 六、已知边界

- **24px 以下的内部黑线**（如炮塔圈）靠几何做不出来，需要渲染后手工描边
- 程序化模型细节比 Westwood 的手工模型少，结构层次偏弱
- 载具每帧约 200-250 个不透明像素，RA 原版 209-274，接近

## 七、参考事实

测量 RA 原版 `2tnk` 的 8 个朝向：

```
朝向    bbox      不透明像素   颜色数
 0     13x17        209         13
 1     17x18        216         13
 2     21x18        227         12
 3     24x18        243         11
 4     24x18        254         12
 5     24x17        265         11
 6     24x16        270         12
 7     24x14        274         12
```

**像素数单调递增，质心固定在 (17.7, 19.4)，颜色数稳定 11-13。**

这说明 RA 的载具是 **3D 渲染**的（不是手绘），
所以我们的技术路线和 Westwood 一致 —— 差别在模型的精细度和后处理参数。
